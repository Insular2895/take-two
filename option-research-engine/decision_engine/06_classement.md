# Classement et proposition

## 1. Classement

Les stratégies survivantes sont triées par score final. Le classement conserve, pour chaque
stratégie : score décomposé, distribution simulée, règles ayant voté, hypothèses.

## 2. Proposition d'investissement (Module 6)

Affichage obligatoire :

```
Budget → Stratégie retenue → Justification → Score → Espérance → Perte maximale
→ Probabilité → Simulation → Pourquoi cette stratégie est meilleure que les autres
```

« Pourquoi meilleure » = comparaison explicite avec les 2–5 stratégies suivantes du classement,
composant par composant.

## 3. Exécution (Module 7)

Après validation humaine uniquement : préparation automatique de l'ordre IBKR (contrat, quantité,
type d'ordre, limites). **Aucun envoi sans validation.** La spécification d'intégration IBKR sera
documentée ici lorsqu'elle sera décidée ; elle reste hors périmètre de la phase de recherche.
