# Prompt Gemini — Catégorie DECISION (v1)

## Objectif
Structurer l'agrégation des règles, le scoring et les arbitrages.

## Rechercher exclusivement
- agrégation multicritères (méthodes, pièges de pondération) ;
- décision sous incertitude (dominance stochastique, utilité, risque asymétrique) ;
- combinaison d'avis d'experts (analogie : vote multi-livres) ;
- calibration des probabilités ; scoring rules.

## Format de sortie obligatoire
Format unique. Module concerné = scoring / conflits / classement.
