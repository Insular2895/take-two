# Prompt Gemini — Catégorie VALUATION (v1)

## Objectif
Évaluer si le marché sous-estime ou surestime l'entreprise.

## Rechercher exclusivement
- attentes implicites (méthodes d'extraction depuis le prix) ; valorisation ;
- DCF (hypothèses critiques, pièges) ; multiples (choix, normalisation) ;
- scénarios ; consensus ; surprises positives / négatives ;
- révisions de bénéfices ; création de valeur.

## Transformation attendue
Des règles reliant un signal de valorisation à une décision d'option (sélection du sous-jacent,
horizon d'échéance, asymétrie attendue).

## Format de sortie obligatoire
Format unique. Toute règle doit préciser les données d'entreprise nécessaires (Module 3).
