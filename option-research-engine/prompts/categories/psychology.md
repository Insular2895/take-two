# Prompt Gemini — Catégorie PSY (v1)

## Objectif
Empêcher les erreurs humaines. Les informations extraites servent UNIQUEMENT à construire des
garde-fous automatiques (interdictions, alertes, délais imposés) — jamais des signaux d'achat.

## Rechercher exclusivement
- biais cognitifs (avec leur manifestation concrète en trading d'options) ;
- erreurs de décision ; revenge trading ; FOMO ; surconfiance ;
- discipline (mécanismes de respect des règles) ;
- erreurs de sortie ; erreurs de renforcement ; erreurs de gestion des gains.

## Transformation attendue
Chaque biais devient une règle de garde-fou : Condition (situation détectable dans les données ou
le journal) → Action (bloquer, alerter, imposer un délai, exiger une justification).

## Format de sortie obligatoire
Format unique. Module concerné = garde-fous / maintenance / journal.
