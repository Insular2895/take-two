# Prompt Gemini — Catégorie PROBA (v1)

## Objectif
Fonder chaque décision sur l'espérance et les distributions, pas sur des points.

## Rechercher exclusivement
- espérance mathématique appliquée aux trades ; distributions de rendements (queues épaisses) ;
- probabilités conditionnelles utiles (ex. P(toucher le strike avant T)) ;
- erreurs classiques de raisonnement probabiliste en trading ;
- méthodes d'estimation des probabilités depuis les prix d'options.

## Format de sortie obligatoire
Format unique. Module concerné = simulation / scoring.
