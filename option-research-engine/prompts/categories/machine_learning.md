# Prompt Gemini — Catégorie ML (v1)

## Objectif
Utiliser le ML uniquement là où il apporte un avantage objectif et validable.

## Rechercher exclusivement
- validation spécifique aux séries financières (purged CV, embargo) ;
- feature engineering pertinent pour options/volatilité ;
- détection d'overfitting ; importance des features ;
- cas documentés où le ML sous-performe des règles simples (à consigner aussi).

## Garde-fou
Aucune règle ML n'entre dans le moteur sans protocole de validation dédié dans `validation/`.

## Format de sortie obligatoire
Format unique.
