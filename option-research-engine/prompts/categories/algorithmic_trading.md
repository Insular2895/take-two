# Prompt Gemini — Catégorie ALGO (v1)

## Objectif
Industrialiser la recherche et l'exécution sans dégrader la rigueur.

## Rechercher exclusivement
- pipelines de données (qualité, survivorship bias, alignements temporels) ;
- architecture des systèmes de recherche (séparation données/signaux/exécution) ;
- exécution : types d'ordres, slippage, impact du spread des options ;
- journalisation et reproductibilité des expériences.

## Format de sortie obligatoire
Format unique. Module concerné = collecte / exécution / robustesse.
