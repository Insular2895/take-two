# Prompt Gemini — Catégorie TRADSYS (v1)

## Objectif
Construire les meilleures règles de maintenance.

## Rechercher exclusivement
- règles d'entrée ; règles de sortie ;
- trailing stops (méthodes d'ancrage, distances, conditions) ;
- stops dynamiques ; stops temporels ; systèmes de suivi ;
- money management appliqué aux systèmes ;
- optimisation de paramètres ; robustesse des systèmes.

## Transformation attendue
Chaque mécanisme devient une règle paramétrable (le paramètre est une variable, jamais une
constante) que l'optimiseur pourra tester.

## Format de sortie obligatoire
Format unique. Module concerné = maintenance / trailing_stop / vente / rolling.
