# templates/ — Modèles officiels

## Rôle
Fournir les modèles à copier pour toute nouvelle entité du repository. Ne jamais créer une fiche,
une règle ou un journal sans partir du modèle correspondant.

## Contenu
| Fichier | Usage |
|---|---|
| `fiche_livre.md` | Nouvelle entrée de la bibliothèque (`books/fiches/`) |
| `regle.md` | Nouvelle règle (`rules/<CAT>/`) — copie du format officiel |
| `fiche_repository.md` | Étude d'un repo open source (`research/`) |
| `journal_decision.md` | Journal d'une opération (futur moteur, Module 11) |
| `../evidence/templates/decision_evidence.md` | Dossier de preuve par décision avant activation |
| `prompt_categorie.md` | Nouveau prompt de catégorie (`prompts/categories/`) |

## Conventions
Les modèles sont versionnés : toute modification d'un modèle est notée en bas de fichier et ne
s'applique qu'aux nouvelles entités (pas de migration rétroactive silencieuse).
