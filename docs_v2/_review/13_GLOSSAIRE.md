# Glossaire

| Terme | Explication simple |
|---|---|
| Ask | Prix auquel on peut acheter selon la quote observée |
| Bid | Prix auquel on peut vendre selon la quote observée |
| BAG | Contrat IBKR représentant plusieurs jambes comme un combo |
| Callback | Fonction appelée par l’API IBKR lorsqu’une donnée arrive |
| `conId` | Identifiant contractuel IBKR |
| Entitlement | Permission de recevoir un type de donnée de marché |
| Hard gate | Condition bloquante qu’un score ne peut pas contourner |
| Holdout | Données conservées hors développement pour un dernier test |
| IV | Volatilité implicite |
| OI | Open interest, nombre de contrats ouverts selon la source |
| OPRA | Flux consolidé américain des options listées |
| P | Mesure/probabilité du monde réel estimé |
| Q | Mesure risque-neutre utilisée pour le pricing |
| Paper | Environnement broker simulé, sans capital réel |
| Pacing | Limites de fréquence et de volume des appels API |
| Pareto | Ensemble de compromis non dominés entre plusieurs objectifs |
| Provider timestamp | Heure donnée par le fournisseur, distincte de la réception locale |
| Read-only | Capacité de lecture sans mutation broker |
| Shadow | Décisions prospectives enregistrées sans effet broker |
| Snapshot | Vue bornée des données à un instant/cutoff |
| Spot | Prix du sous-jacent |
| Stale | Donnée trop ancienne pour l’usage prévu |
| Synthetic combo | Prix reconstitué à partir des bid/ask des jambes |
| TWS/IB Gateway | Applications IBKR qui authentifient l’utilisateur et exposent le socket local |
| What-if | Estimation broker de l’effet marge/commission sans transmission finale, mais utilisant potentiellement le domaine ordre |
